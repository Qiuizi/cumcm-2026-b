## 一、方法（可直接写入论文的骨架）

### 1.1 计费模型（把一切"动作"折算成虚拟时间）

| 动作 | 虚拟时间成本 |
|---|---|
| 移动 | `d / 5`（距离 m / 5 m·s⁻¹） |
| 切换频道 | 1 s / 次 |
| 检测 `/measure` | 5 s / 次 |
| 清除失败 | 3 s / 次 |
| 清除成功 | 5 s / 次 |

⇒ 一局的虚拟时间恒等式 **`T = L/5 + 5M + S + 3F + 5N`**（L 移动距离、M 检测、S 切频、F 失败清除、N 成功清除）。
本队实现对该恒等式逐局复算，残差 ≤ 1e-6 s（验收记录：`experiments/stage3_candidate/validation_12runs.json`）。

### 1.2 P3：固定覆盖站 + 168 扇区单元证据链

- 固定覆盖站：**7 点 @ r = 999**（`EvidenceTrackerP3.search_points`）；
- 覆盖证书：**168 个扇区单元**被"存在一个静默测站且最远点 ≤ 1000 m"排除；
- `no_signal` 的语义是**排除以测站为中心、半径 1000 m 的圆盘**（`B(q, 1000)`），而不是"该频道不存在"。

### 1.3 P4：25 点三角网 + 可证否的覆盖证书

- 测站网：**25 点 = O + 8 @ 990 + 16 @ 1840**（`EvidenceTrackerP4`）；
- 证书：**32 个三角形**，"三顶点静默且三边 ≤ 1000 m ⇒ 三角形内任意点不可能是源"；
- 精确刻画：候选真值点 `x` 被排除 ⟺ `x ∈ conv{ q ∈ Q : ‖q − x‖ ≤ 1000 }`；
  等价判据：以 `x` 为心的环向角隙**最大值 ≤ π**；
- 硬下界（与布局无关）：
  - 若要求 P4 证书对 Ω 精确成立，**外环半径 ≥ 1800 m**；
  - 半径 1800 的边界圆上，单圆盘截得的最大弧长 **67.49798°**（在 `d* = sqrt(1800²−1000²) = 1496.663 m` 处）；
  - **3-重覆盖**至少需要 `|Q| ≥ 17` 个测站；**1-重覆盖**至少 `|Q| ≥ 6`；
- 关键设计性质（内环半径敏感性）：内环从 990 调到 900 时，"严格放行率"从 **1.0000 掉到 0.4718**
  ⇒ 现行 990/1840 是**在严格判据下几乎不损失、且点数可行**的选择。

来源：`experiments/roadmap/ROUTES_研究报告.md`（§LB2、布局敏感性表）。

### 1.4 局部决策：安全网格 + 清除计划 + J0/Jq 门槛

- 每个目标维护一个**保守安全网格**（由测向/静默/近距/清除失败四类观测裁剪）；
- 已收缩到可一步安全清除时直接清除（`safe_clear_guaranteed`）；
- 否则构造**有限清除计划**（多步），并把"当前计划在所有采样场景上的平均代价"记为 **J0**；
- 对候选补测点 `q` 计算 **Jq**（闭环：假设反馈 → 更新网格 → 重新构造计划 → 逐场景代价期望）；
- **门槛**：仅当 `min J(q) + margin < J0` 才派发补测，否则直接按计划清除。

### 1.5 历史接收模型（候选版，唯一改动切片）

| 项 | 值 |
|---|---|
| 假设（粒子）数量 | `n_hyp = 512` |
| 源类型先验 | `p_dir = 0.5`（**建模假设，非题面事实**） |
| 接收半径先验 | `R ~ U[1000, 1500]`（**建模假设**） |
| 朝向先验 | `u ~ U[0, 2π)`（**建模假设**） |
| 测向容差 | 继承安全网格自身 `eps_deg` |
| 条件化抽样 | `pool_factor = 40`，`max_rounds = 6` |
| 抽样种子 | `20260912 + 131 × channel`（同一目标的 R/u 在各观测间固定） |
| 更新规则 | 用**全部历史观测**重新过滤相容假设（阳性+阴性联合），只剔除、不重抽 |
| 回退规则 | 假设集为空 ⇒ 预测返回 `None` ⇒ 决策器**逐字回退**冻结公式并记录原因 |

实现方式（可在论文中强调**可审计性**）：候选决策主体由**构建期生成器**从冻结基线源码生成，
只替换"接收概率"一个切片，其余**逐行相同**；运行期不 `exec`、不读外部源码。
校验：`verify_equivalence.check_source_locality()` —— r1 为 **277 vs 277 行逐行相同**，
r2（含 D1 修复）为 **281 vs 281 行**，`runtime_uses_inspect_or_exec = False`。

来源：`experiments/stage3_candidate/STAGE3_REPORT.md`、`FREEZE.json`、`verify_equivalence.py`。

### 1.6 工程协议对齐（论文中作为"可信度与可复现性"支撑）

- **通信**：动作幂等（同一 `request_id` + 同一内容重复提交不重复执行）；
  错误分类 `400/404/405/409/413/415` 立即失败不重试，`429/500` 才退避重试且**复用原 id**；
  同时校验 HTTP 状态与 `accepted`；重试耗尽时如实记录"未完成"，不伪造 `COMPLETED`。
- **现实预算**：本局可用现实时间取 `/enter` 的 `remaining_real_duration_s`（配置上限只作封顶），
  用**单调时钟**固定起点；通信重试只消耗预算；截止后不再派发任何测量/清除。
- **运行产物外置（D2）**：默认日志写在包外独立目录，发布包重建不会删除历史记录。

### 2.3 机制辨析：「预测网格空集异常」到底对应哪个计数（有独立佐证）

| 概念 | 计数/返回 | 触发点 |
|---|---|---|
| 模型假设集为空（**回退**） | `call_fallback_count` + `decision_fallback_count` + `fallback_reason_hist` | predictor 不可用（`n_alive=0`） |
| **「预测网格空集异常」** | `empty_prediction_count`（同时 `unrepresentable_prediction_count` +1） | 候选打分中"正概率假设下的测向反馈"与克隆安全网格**全局矛盾**（裁剪被**拒绝**并置 `contradiction`） |
| 实际安全网格不可用 | 返回 `fail`（`empty_grid_no_valid_state` / `model_contradiction_…`） | `grid.count()==0` 或 `contradiction` |

- 关键更正：P4 路径的网格裁剪运算符**不允许把存活集裁空**（会拒绝该裁剪并置矛盾标记），
  因此该计数的名字里的"空集"**并未真的发生**；
- **独立佐证**（复用既有验收日志）：history_candidate 一局 `预测网格空集异常 = 5 次`，而同局
  `decision_fallbacks = 0、call_fallbacks = 0、fallback_reason_hist = {}`（**零回退**）；
  同场景 stable 基线为 **0 次** ⇒ 二者**不可等同**；
- 合成机制探针：同一几何 + 同一候选，**无模型 → +0；模型给出正概率 → +1**（该事件只在模型路径出现）。

文件：`results/delivery/LONG_CLEAR_3RUNS_诊断报告.md`、`empty_semantics_check.json`。

## 三、局限与"不可宣称"清单（论文须如实写出）

1. **官方逐动作日志缺失**：三局困难频道（020309/020517/020723）在本机**没有客户端逐动作日志**
   （工作区 01:39:44→02:40:40 空档；全盘按名检索无果），服务器侧只有聚合计数，
   `.jlog/.psum` 为 gzip+AES-256-GCM 加密不可读。⇒ 因此**不能**给出这三局的逐频道快照、
   也不能做"几何不确定性 vs 模型失效 vs 评分缺陷"的逐目标归因（只有运行级分解与一个可证伪假设）。
2. **无真值**：源的真实位置不可从接口获得；论文中**不得**把"最终清除坐标"当作真值使用。
3. **先验是假设**：`p_dir`、`R`、`u` 的分布均为建模假设，不是题面事实；敏感性测试只覆盖网格布局与半径，
   未做先验的系统性标定。
4. **官方成绩的表述边界**：本队官方运行为**练习局**（统计库），且**未保存逐动作日志**；
   论文中不得使用"官方成绩/官方排名"字样；本地 12 局配对数据是**本地参考环境**结果。
5. **D1/D2 修订的身份边界**：r2 只改了一条异常分支的文案与日志落盘位置，**不改变数值行为**；
   但 r2 指纹与 r1 不同 ⇒ 引用历史结果必须标注 r1 指纹（见文首引用规范）。
6. **`empty_prediction_count` 的命名与实际语义不符**（见 §2.3），论文中引用该计数时须给出准确定义。
7. **模型未自动启用**：候选版需显式 `--profile history_candidate`；默认仍为 `stable`。
8. **P4 网格不收缩的语义**：阴性观测（`no_signal`）在 P4 不使网格收缩（`shrunk=0` 已验证），
   其对 P4 的作用是"排除圆盘"而非"裁剪网格"；讨论"信息增益"时不可混用两种语义。
