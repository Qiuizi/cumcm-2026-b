# 阶段2 结论：历史观测条件下的接收预测（臂 C）

> 本轮只回答两个问题：
> **① 历史观测是否改善了决策？ ② 它是否比 k=1 简单止损更值得继续研究？**

---

## 0. 结论

| 问题 | 回答 | 依据 |
|---|---|---|
| **① 历史观测是否改善决策** | **是**（在预注册的 3/3 局上） | 臂 C 相对基线 A：平均 **−460.015 s**，中位 −407.548 s，**最差一局仍是 −395.739 s**，胜/平/负 = **3/0/0**；9 局全部通过完整清除与计费闭合验收 |
| **② 是否比 k=1 更值得继续研究** | **是** | 臂 C 相对臂 B：平均 **−511.309 s**，中位 −270.591 s，最差 −155.378 s，胜/平/负 = **3/0/0**；而臂 B 相对基线 A 只有 2胜1负、且含一局 **+700.410 s** 的大退步 |

**机制层的差别一句话**：B 与 C **消除的盲测次数完全相同**（289/233/160），
差别在下游 —— B 拿到"止损"信号后立刻背上昂贵的清除计划（失败清除 136/232/186），
C 用假设模型判断"哪里还收得到"，把清除放在更可能命中的位置（失败清除 11/138/117）。

### 2.1 逐局分项（CSV 原始值）

要点：
1. **B 与 C 的 `no_signal` 总数逐局完全相同**（289 / 233 / 160）——两者都在同一处切断盲测链，
   所以两者的差异**不可能**来自"消除盲测"，只能来自切断之后做什么。
2. **C 在 3/3 局的 L 与 M 都不大于 A**（L：22 162<23 425、33 665<35 039、24 834<26 478；
   M：312<331、259<298、192<237），与"避免重复进入盲区"的预期一致。
3. **B 的失败清除次数翻倍**（136 vs A 的 31；232 vs 174；186 vs 64），
   这就是 B 那一局 +700 s 退步的来源；C 的失败清除次数在 10src 局从 31 降到 11。

### 2.3 三次独立运行的确定性

9 局在同一预注册场景上跑了三次（第一次因 `audit()` 漏字段、第三次因探针口径修正而重跑），
**逐局 T、L、M、S、F、N 完全一致，最大差异 0.000 s**（见
`results/stage2_paired_9runs_run1_backup.json` 与当前 `stage2_paired_9runs.json` 的比对）。
这说明"配对差值"不是运行抖动，而是机制差异。

## 3. 机制验证（三. 的四项确定性检查）

| 检查 | 结果 |
|---|---|
| **1. 新观测改变相容假设与下一点接收预测** | 是。合成确定性状态（同一粒子群上的纯过滤对比）：相容假设 **236 → 20**，新阴性观测剔除 216 个；4 个探针点的 P_recv **全部改变**（0.877→0.25、0.962→0.65、0.915→**0.0**、0.915→**0.0**） |
| **2. 同一未清除目标同一位置结果一致** | 是。模型参数/预测/重复调用逐位一致；环境同点同频道两次测量结果与示向度完全相同 |
| **3. 预测不修改真实安全网格** | 是。`alive` 位图逐位不变，单元数 10941 → 10941 |
| **4. 实际改变补测点或补测/清除选择** | 是。真实运行 22 个决策中 **2 次动作类型改变、4 次补测点改变**；例子见下 |
| 附：**源码机检** | 臂 C 的决策主体由冻结源码程序化生成，删掉被替换切片后与冻结版**逐行相同（277 行 vs 277 行）** |

### 3.1 改变动作的完整例子（动作类型翻转：measure → clear）

场景：P4，seed 7701，10 源。频道 12。

**决策时已有观测（10 条）**

```
no_signal @ [0.00, 0.00]        no_signal @ [990.00, 0.00]
no_signal @ [700.04, 700.04]    no_signal @ [0.00, 990.00]
no_signal @ [-700.04, 700.04]   no_signal @ [0.00, 1840.00]
no_signal @ [704.14, 1699.94]
direction @ [1301.08, 1301.08]  svd = 226.62°
direction @ [1232.39, 1228.39]  svd = 227.17°
direction @ [962.62, 939.18]    svd = 226.88°
```

**更新前后的接收预测（同一粒子群上的纯过滤对比）**

| 项 | 更新前（用前 9 条观测过滤） | 更新后（用全部 10 条观测过滤） |
|---|---|---|
| 相容假设数 | 306 | **7**（第 10 条观测剔除 299 个） |
| P_recv（基线选点 `[715.56, 675.46]`） | 0.000 | **0.000** |
| P_recv（臂 C 选点 `[950.79, 930.40]`） | 0.131 | **1.000** |

**J0 / Jq 与实际选择**

| 臂 | 动作 | 位置 | J0 | Jq | 门槛判定 |
|---|---|---|---|---|---|
| 基线 A | `measure` | `[715.56, 675.46]` | 239.017 | 204.267 | Jq + 5 < J0 ⇒ 补测 |
| **臂 C** | **`clear`** | `[950.79, 930.40]` | 239.017 | 242.073 | Jq + 5 > J0 ⇒ 直接清除 |

差异维度：**action_type**。

读法：基线选中的补测点，在假设模型下的接收概率是 **0.000**（该点落在全部相容假设的
波束之外或半径之外，去了必然是又一次盲测）；而基线用的是"距离 ≤ 1000 就该收到"的
固定公式，看不见这件事。臂 C 因此不再往那里走，直接提交清除计划。

### 3.2 动作翻转的两个方向（9 局配对中共 8 次）

| 方向 | 次数 | 含义 |
|---|---|---|
| `measure → clear` | **6** | 拒绝一次模型判定"必然收不到"的补测（减少重复进入盲区） |
| `clear → measure` | **2** | 在没有盲测的情况下，模型仍能找到接收概率可观的点，于是**不**转入昂贵的清除（避免过早清除） |

第 2 类正是 k=1 简单止损会做错的地方：k=1 只看"网格是否收缩"，
一旦盲测就强制清除；而臂 C 用联合假设判断"还有没有值得去的地方"。
例：`P4-13src-seed8813` 频道 11，基线因 `Jq=190.5 > J0=183.9` 判定直接清除，
臂 C 在同一状态上给出 `Jq=167.7 < J0=183.9`，选择继续补测。

### 3.3 8 次翻转按"驱动来源"分解（如实区分）

| 驱动来源 | 次数 | 判据 |
|---|---|---|
| **最新一条观测确实改变了预测** | **5** | 同一点上的 P_recv 在更新前后发生变化（逐条可查 `stage2_key_decisions.csv`） |
| 仅由"初始化时已条件化的先验"驱动 | **3** | 该次决策的 P_recv 更新前后不变，动作差异来自假设集在先验上的差异 |

更新驱动的 5 次里最典型的一条：`P4-13src-seed8813` 频道 7，第 4 条观测把
基线选点的 P_recv 从 **0.791 打到 0.000**、把臂 C 选点的 P_recv 从 0.926 打到 0.111，
于是基线仍在补测、臂 C 转入清除。

## 4. 保留意见（必须与结论一起读）

1. **样本量 3 局**。这是本阶段**预注册的上限**，因此 3/0/0（C 对 A、C 对 B）**不足以**给出
   尾部风险上界或置信区间，也**不能**把 −460 s / −511 s 的均值外推到未测场景。
2. **按指示不使用"±300 秒噪声带"否定配对差值**。配对差值按原样报告，
   不因与所谓噪声带同量级而作废；同时也不据此宣称统计显著。
3. **全部失败与退步都已保留**：臂 B 的 **+700.41 s** 退步完整保留在 CSV 中；
   臂 C 在本轮 3 局**没有退步案例**可保留（3 局全为获益），这一点如实说明。
4. **假设集耗尽**：固定粒子表示在观测较多时会耗尽。seed 8813 有 1 个频道在 3 条观测后耗尽，
   该决策整体回退到冻结公式并记录原因（造成 250 次逐调用回退）。
   回退比例整体很小（94 个决策中 2 次），但这是该轻量表示的**结构性限制**。
5. **建模假设不是题面事实**：定向源比例 0.5、`R ~ U[1000,1500]`、朝向均匀分布，
   均为构造先验假设集的**建模约定**；本阶段未搜索这些参数。
6. **未改动项**：P3、P4 覆盖布局、扫描规则、全局调度、候选补测点生成、完整清除计划、
   结束判据——全部未动；三臂只替换 `eng.local_decision` 一个对象。
7. **真值隔离**：真值只用于本地环境生成反馈与事后验收；假设集的位置样本全部取自安全网格，
   在线选点与清除规划不接触真值。预测过程不修改安全网格，不参与判空与结束判据。
