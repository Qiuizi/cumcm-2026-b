# P4 搜索覆盖与路线组织重新设计 · 结论

**核心问题的回答：在当前"每个空频道都必须用静默测站覆盖整个 Ω"的结束证据要求下，P4 整局时间无法接近 4000 秒。**
限制来自覆盖网的几何下界，不是路线启发式、不是实现细节。

---

## 一、候选选择理由（两种机制对比）

| | M1 环状网（基线） | M2 三角格子补丁网 |
|---|---|---|
| 必访位置集合 | O + 8@999 + 16@1840（同心环） | 三角格子六边形补丁（基矢 1000 m） |
| 覆盖证明 | 三角形三顶点同频道静默 + 三边 ≤ 1000 | 同类型（格子三角形） |
| 合法最小规模 | **25 点** | L=2（19 点）内切半径 1732 < 1800 **不合法**；L=3（37 点）才合法 |
| 开放路线 | **17961.20 m = 3592.24 s** | L=3：36000 m = 7200 s（同口径） |
| 逐空频道检测 | 25 次 | 37 次 |
| 接入目标绕行 | 基线实测项 | 同 |

**M2 严格更差**（点数 37 > 25，路线 2 倍以上），故候选仍取环状族，但做参数化与证书改造。

**M1 家族内的最小性（离线扫描，非仿真）**

- 对齐双环族 O + n1@r1 + 2n1@r2 可行性扫描：n1 ≤ 7 **全部不可行**；最小可行 = n1=8, n2=16（25 点）。
- Delaunay 构型搜索：n1∈[3,10] × r1∈[500,1000] × n2∈[10,20] × r2∈[1800,2100] × 3 种相位，共 **72072 组**；
  满足"所有 Delaunay 边 ≤ 1000 m 且凸包内切半径 ≥ 1800 m"的只有 14 组，**点数全部 ≥ 28**；
  **不存在少于 25 点的合法覆盖网**。
- 路线：独立多起点 2-opt/Or-opt 复算基线 25 点网得到 **17961.20 m**，与引擎实测完全一致 → **路线启发式已最优，无改进空间**。

**候选实现**：覆盖网参数化 (n1, r1, n2, r2)，三角剖分**由点集生成**（不再逐条硬编码），
结束证据改为**连续局部凸包证书的精确实例**。r1 由 999 取 990 的**唯一依据是覆盖路线最短**
（17912.98 m vs 17961.20 m ≈ −48 m ≈ −10 s），与实测用时无关。

## 二、覆盖证明（连续区域，非采样）

对每个仍未知的频道 j，须在整个 Ω = B((0,0),1800) 上成立
x ∈ conv{ q ∈ Q_j^- : ||q − x|| ≤ 1000 }，其中 Q_j^- 只含该频道实际取得 no_signal 的测站。

本候选使用的**严格充分条件**：三角形三顶点同频道静默，且**三边 ≤ 1000 m**。
理由：conv(T) 上到各顶点的最大距离在顶点处取得，三边 ≤ 1000 即保证 conv(T) 内所有 x 满足
max_{q∈T} ||x − q|| ≤ 1000，于是 x ∈ conv{静默且在 1000 m 内的测站}。

**精确核验（不使用有限采样）**，certificate_geometry() 输出：

| 项 | 值 | 判定 |
|---|---|---|
| 覆盖点数 / 三角形数 | 25 / 32 | — |
| 三角形最大边长 | **999.911 m** | ≤ 1000 ✓ |
| 三角形面积和 | 10364904.229 m² | 与外环多边形面积**完全相等** → 无缝无重叠 ✓ |
| 外环凸多边形内切半径 | **1804.645 m** | ≥ 1800 → 覆盖 Ω ✓ |
| certificate_valid | **True** | ✓ |

约束遵守：不用单次 no_signal 宣布不存在；不用全局凸包代替方向覆盖证明；
**保留 K=16 上限排除规则**；继续清除所有 FOUND 目标；经过某位置或清除其他频道都不自动为该频道增加检测证据。

## 三、闭合的 4000 秒预算（10 源 / seed 7210）

| 项目 | 数值 | 性质 |
|---|---|---|
| ① 覆盖路线移动 | **≥ 3592.24 s**（17961.20 m） | **严格下界**（25 点最优开放路线，72072 组搜索证明无更小网） |
| ② 空频道检测 | **≥ 1250.00 s**（10 × 25 × 5 s） | **机制下界**（每个空频道需在覆盖网全部顶点取得 no_signal） |
| ③ 成功清除 | **= 50.00 s**（5 × 10） | **严格下界** |
| **①+②+③** | **≥ 4892.24 s** | **已超过 4000 s → 不可达** |
| ④ 切频 | 319.00 s | 可构造（实测） |
| ⑤ 失败清除 | 114.00 s | 待验证估计（由局部定位决定） |
| ⑥ 已发现频道检测 | 535.00 s | 待验证估计 |
| ⑦ 接入目标的额外绕行 | 1317.06 s | 待验证估计 |
| **合计** | **7177.30 s** | 与基线实测 7177.31 s 闭合 |

同口径：**13 源** 3592.24 + 7×25×5=875 + 5×13=65 → **≥ 4532.24 s > 4000 s**（基线 7904.58 s）。
**16 源**可用 K=16 上限提前结束搜索，路线下界不适用；但该局面由**接入目标绕行**主导
（基线中定位补测 2180.32 s + 清除移动 1636.93 s = **3817.25 s**），属"保留的局部定位与完整清除计划"，本轮不得改动。

**路线缩短不能直接当成整局省时**：① 只是移动下界，⑥⑦（接入目标后新增的实际路程）必须单列，两者相加才是整局移动。

| P4H-13src-7213 | 13 | 7904.58 | 7849.12 | **+55.46 s** | 28852.9 / 28725.6 | 60 / 50 | PASS / PASS |

T = L/5 + 5M + S + 3F + 5N 核算残差 ≤ 4.9e-4 s，现实耗时 29.6 / 91.1 / 106.0 s。
平均 Saved_T = **+385.06 s**（3 胜 0 负）。

### 但这不是可归因于覆盖结构的收益

对 r1 做的**同三例敏感性诊断**（同一批种子、同一配置，只改内环半径）：

| r1 | 三例均值 T |
|---|---|
| 980 | 8119.76 s |
| **990（候选）** | **7282.05 s** |
| 999（基线） | 7667.12 s |
| 1000 | 7731.66 s |

**敏感性带宽度 = 837.71 s**，比路线变化（≈10 s）大两个数量级。把内环 8 个点移动 10–20 m 就能让三例均值摆动 ±400 s，
这是**确定性轨迹分歧**（测站位置微变 → 示向度误差变 → 决策路径变），**不是覆盖组织方式带来的系统性收益**。
因此**不把 +385 s 计为覆盖改造收益**；按"不围绕种子调参"，**不据实测用时挑选 r1**。
这同时说明：**三例配对无法分辨 400 s 量级以下的差异**。

## 五、限制所在（本轮核心结论）

1. **覆盖网规模不可减**：连续覆盖 Ω 需要边长 ≤ 1000 m 的三角剖分；面积下界要求 ≥ 24 个三角形，
   外边界闭合 Ω 要求 ≥ 12 个外环点；几何可实现的最小规模就是 **25 点**（72072 组 Delaunay 搜索未找到更小者）。
2. **覆盖路线不可减**：25 点最优开放路线 17961.20 m = 3592.24 s，与引擎实测一致。
3. **空频道检测不可减**：每个空频道的结束证据都要求它在覆盖网**全部 25 个顶点**取得 no_signal，A × 25 × 5 s 是机制下界。
4. 三者相加对 10 源（4892.24 s）与 13 源（4532.24 s）已超过 4000 秒；16 源虽可提前结束搜索，
   但 3817.25 s 的接入目标绕行由保留的局部组件决定。
5. 因此 **4000 秒与 3000 秒目标在本轮约束下均不可达**，也没有找到能明显降低成本的覆盖构造。
   按停止条件：不把 +385 s 包装成收益，三例后停止，不围绕种子调参。

**若未来要真正突破**，需要改变的是"空频道必须由静默测站覆盖整个 Ω"这一证据强度本身
（例如取得与真值无关的额外环境先验），而不是覆盖网的形状或访问顺序。
